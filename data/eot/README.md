# 균시차 표

`calculateSaju(…, { equationOfTime: true })`와 `getEquationOfTime`이 쓰는 균시차(equation of time) 표의 원본입니다. 1.3.0부터 씁니다.

균시차 = 시태양시 − 평균 태양시. 해시계가 평균 태양시보다 빠르면 +입니다(11월 초 약 +16분 26초, 2월 중순 약 −14분 13초).

## 파일

| 파일 | 내용 |
|---|---|
| `eot-18xx.tsv`·`eot-19xx.tsv`·`eot-20xx.tsv` | 날마다 12:00 UT의 균시차. 1799-12-30 ~ 2051-01-02, 91,680일(앞뒤 이틀은 UTC−12~+14 시계와 보간용) |
| `horizons-sample.tsv` | JPL Horizons에서 받은 대조 표본 385개 |

머리줄 `jd	eot_sec`.

| 칸 | 뜻 |
|---|---|
| `jd` | 율리우스 적일(정수 = 그날 12:00 UT) |
| `eot_sec` | 균시차(초, 소수 둘째 자리) |

## 만든 법

`npm run gen-eot-source`(`scripts/build-eot-source.mjs`)가 Meeus 『Astronomical Algorithms』(2판) 28장 식으로 셈합니다.

    E = L0 − 0.0057183° − α + Δψ·cos ε

- `L0`: 태양 평균 경도(식 28.2)
- `α`: 태양 겉보기 적경 — 25장의 고정밀법. VSOP87 줄인 급수(부록 III)로 지심 황경·황위·거리를 구하고 FK5 보정, 장동(22장 짧은 식), 광행차(−20.4898″ ÷ R), 참 황도 경사각을 넣습니다
- 역학시 = UT + ΔT(Espenak·Meeus 2006 다항식). ΔT가 1분 틀려도 균시차는 0.01초 안팎만 달라집니다

`npm run gen-eot-table`(`scripts/build-eot-table.mjs`)이 이 원본으로 `src/data/eot-table.ts`를 만듭니다.

- 날마다 원본에서 **±0.75초 안의 정수 초**를 고르되, 이차 차분(`v[i] − 2·v[i−1] + v[i−2]`)이 0인 날이 가장 많아지는 줄을 고릅니다(비터비 — 이차 차분 ±1은 1점, ±2는 2.5점, 합이 가장 작은 줄).
- 처음 두 값은 숫자로, 그 뒤 이차 차분(−2~+2)은 글자 하나(문자 코드 64 + 차분)로 적습니다. 절입 시각 표(`data/terms`)와 같은 틀입니다.
- 생성할 때 모든 값을 되살려 대조하고, 원본과 0.75초 안인지 확인합니다. 라이브러리는 처음 쓸 때 한 번 풀어 메모리(`Int16Array`, 약 180KB)에 두고, 날 사이는 선형 보간합니다.

생성 파일은 손으로 고치지 않습니다(`npm run check-tables`로 낡았는지 봅니다).

### 왜 그냥 반올림하지 않는가, 왜 1800년부터인가

균시차의 하루 사이 이차 차분은 ±0.9초 안이라, 초로 반올림하면 이차 차분이 반올림 잡음 때문에 −2~+2로 고르게 흩어집니다. 그래서 gzip으로 잘 줄지 않습니다.

| 범위 | 고르는 법 | 표 본문 gzip |
|---|---|---|
| 1391~2050 (241,112일) | 반올림 | 약 41KB |
| 1800~2050 (91,680일) | 반올림 | 약 16KB |
| 1800~2050 | ±0.75초 안 비터비(지금) | 약 12KB |

1391~2050 전체는 번들이 gzip으로 20KB 넘게 늘어 1800~2050만 싣습니다. 균시차 표와 그 코드로 늘어난 번들은 gzip 약 18.7KB(기본 압축 수준), 압축 전 약 97KB입니다(1.3.0 전체로는 1.2.0에 견줘 gzip 약 19.3KB).

## 대조 (JPL Horizons, DE441)

`npm run check-eot-horizons`(`scripts/check-eot-horizons.mjs`)가 저장한 표본으로 대조합니다(`--fetch`면 Horizons에 다시 요청 — 80개씩 5번).

Horizons에서 그리니치(경도 0, 위도 0, 높이 0, 대기 굴절 없음)에서 본 태양의 겉보기 시간각(LHA)을 받아 `균시차 = LHA − (UT − 12시)`로 셈했습니다. 시태양시 − 평균 태양시의 정의 그대로라 Meeus 식과 계산 경로가 겹치지 않습니다. Horizons의 UT는 1962년 전 UT1, 뒤는 UTC(UT1과 0.9초 안)입니다.

표본(고정 씨앗 난수): 1900~2050년 12:00 UT 300일, 1800~1899년 12:00 UT 40일, 1900~2050년 마디 사이 아무 시각 30개, 1391·1600·1800년 각 5일(식만).

| 구분 | 개수 | 평균 \|차\|(초) | 최대 \|차\|(초) |
|---|---|---|---|
| 표(라이브러리 값) 1900~2050 | 300 | 0.33 | 1.12 |
| 표 1800~1899 | 40 | 0.29 | 0.67 |
| 표 1900~2050 마디 사이(보간) | 30 | 0.47 | 1.36 |
| 식(원본) 1900~2050 | 300 | 0.26 | 0.89 |
| 식 1800~1899 | 40 | 0.10 | 0.17 |
| 식 1900~2050 마디 사이 | 30 | 0.43 | 1.28 |
| 식 1391년 | 5 | 0.97 | 1.05 |
| 식 1600년 | 5 | 0.24 | 0.27 |
| 식 1800년 | 5 | 0.14 | 0.16 |

라이브러리 값은 목표(최대 5초) 안에서 최대 1.36초입니다. 마디 사이 차이의 대부분은 선형 보간(하루에 균시차가 최대 약 30초 바뀌고, 그 곡률 때문에 보간이 최대 약 0.1초 어긋남)이 아니라 식 자체와 UT1·UTC 차이에서 옵니다. 식은 1391년에도 1초 남짓이라, 번들 크기만 허락하면 범위를 넓힐 수 있습니다.

테스트(`src/__tests__/eot.test.ts`)는 모든 마디가 원본에서 0.75초 안인지와 이 표본에서 1.5초 안인지를 확인합니다.

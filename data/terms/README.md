# 24절기 절입 시각 표

연주·월주의 경계(절입)와 절기 조회 함수(`getSolarTermsByYear` 등)가 쓰는 표의 원본입니다. 1.2.0부터 씁니다.

## 파일

| 파일 | 내용 |
|---|---|
| `solar-terms.tsv` | 1390년 대설부터 2051년 입춘까지 24절기 15,845개. 시간 차례 |
| `uncertainty.tsv` | 해마다 절입 앞뒤 몇 분을 정할 수 없는가(`uncertainMinutes`) |
| `kasi-24div.tsv` | 한국천문연구원 24절기 발표값 1920~2028년 2,616개(대조용 원본) |

`npm run gen-terms-table`(`scripts/build-terms-table.mjs`)이 이 폴더로 `src/data/terms-table.ts`를 만듭니다. 만들 때 모든 값을 되살려 원본과 대조하고, 아래 "성질"과 발표값 2,616개와의 일치를 확인합니다. 생성 파일은 손으로 고치지 않습니다(`npm run check-tables`로 낡았는지 봅니다).

### `solar-terms.tsv`

머리줄 `year	k	utc_minute	source`.

| 칸 | 뜻 |
|---|---|
| `year` | 절기가 든 해(그레고리력. 그 해의 소한부터 동지까지 24개) |
| `k` | 절기 번호 = 태양 겉보기 황경 ÷ 15도. 0 춘분, 3 입하, … 21 입춘, 23 경칩. 홀수가 절(사주 월의 경계) |
| `utc_minute` | 절입 순간을 분으로 반올림한 절대 시각 — 1970-01-01T00:00Z부터 센 분(그 전은 음수). 날짜 표기를 넣지 않아 1582년 전 율리우스력 문제를 피합니다 |
| `source` | `kasi` 1920~2028년 2,616개: 한국천문연구원 발표값. `calc` 나머지 13,229개: 천문 계산 |

### `uncertainty.tsv`

머리줄 `from_year	to_year	minutes`. 폭은 `max(1, ceil((u + 30) / 60))`분이고, u는 그 해 절기 시각의 불확도(초, 주로 지구 자전 보정값 ΔT의 불확도), 30초는 분 반올림의 폭입니다.

| 해 | `uncertainMinutes` |
|---|---|
| 1391~1499 | 4 |
| 1500~1599 | 3 |
| 1600~2042 | 1 |
| 2043~2050 | 2 (ΔT 예측이 해마다 벌어짐) |

### `kasi-24div.tsv`

머리줄 `year	name	locdate	kst`. 한국천문연구원 특일 정보 `SpcdeInfoService/get24DivisionsInfo`(공공데이터포털 15012690, 이용허락 제한 없음)의 응답에서 해, 절기 이름, 날짜(`locdate`), 한국 시각(`kst`, 시분)을 옮겼습니다. 이 서비스는 1919년 이전·2029년 이후를 주지 않습니다(빈 응답).

## 출처와 만든 법

- **1920~2028년**: 한국천문연구원 발표값을 그대로 씁니다. 발표값은 고정 UTC+9 시계에서 분으로 반올림한 값이라(2,616개를 견줘 반올림 가설 2,517개 일치, 버림 가설 1,406개 — 나머지 99개는 모두 반올림 경계에서 5초 안) UTC로 옮길 때 9시간만 뺍니다. 1954~1961년과 서머타임 기간의 발표값도 고정 UTC+9입니다(법정 시계가 아님). 1950년 대한의 `2400`은 다음 날 00:00으로 읽습니다.
- **1391~1919년, 2029~2050년**: 천문 계산 — 태양 겉보기 황경이 15도의 배수에 이르는 순간을 초 단위로 구해 분으로 반올림했습니다(30초부터 올림). 라이브러리 안에서는 계산하지 않고 만들어 둔 표만 씁니다.
- **ΔT(지구 자전 보정)**: 1900년 전은 Morrison·Stephenson·Hohenkerk·Zawilski (2021)를 씁니다.

## 대조

1. **발표값**: 1920~2028년 2,616개가 발표값과 모두 같습니다(생성 스크립트와 테스트가 확인).
2. **독립 출처(JPL Horizons, DE441)**
   - 1900~2100년: Horizons로 구한 절기 순간과 최대 3.4초 차이.
   - 1391~1899년(12,216개): 태양 위치(TT) 차이 1700~1899년 최대 1.9초, 1391~1699년 최대 5.9초(1799년 전은 Horizons의 세차 모형이 다릅니다). 절대 시각(UT) 차이 최대 2.6초.
   - Horizons도 1900년 전 ΔT에 같은 모형(Morrison 외 2021)을 쓰므로, UT 대조는 ΔT 자체의 독립 검증이 아닙니다. ΔT의 불확도는 `uncertainty.tsv`의 폭에 넣었습니다.
3. **겹치는 구간**: 계산값을 1920~2028년에도 만들어 발표값과 견주면 날짜(한국 시각) 2,615/2,616 일치(다른 하나가 1950년 대한 `2400`), 분 2,517 일치, 나머지 99개는 1분 차이(모두 반올림 경계 5초 안). 그래서 1919→1920, 2028→2029 이음매에서 값의 성질이 바뀌지 않습니다.
4. **성질**(테스트가 확인): 이웃한 절기 간격 14~16.5일, 시간 차례로 단조 증가, 절기 번호가 차례로 돎. 해 기준 조회(절입 순간을 라이브러리 날짜로 옮긴 해로 묶음)는 해마다 24개 — 다만 1391~1581년은 율리우스력 날짜라 그 해의 24개가 대한부터 다음 소한까지이고, 1582년은 10월 5~14일이 없어 23개입니다.

## 정오 직후 절입

절입이 한국 시각 12:00:01~12:00:29인 날은 표의 분이 12:00이 되어, 날짜만 넣은 결과(그날 정오의 값)가 새 달입니다. 1391~2050년에 사흘(1587-03-06, 1660-04-04, 1809-09-08)이고 1900년 뒤에는 없습니다. 라이브러리는 이 표를 정답으로 둡니다(날짜만 넣은 결과 = `getGapjaAt(…, 12, 0)`). 세 날 모두 `uncertainMinutes` 안입니다.
